# Password Health Checker

A chat-based password management health checker with:
- Next.js 15 + TypeScript + Tailwind frontend
- FastAPI backend managed with uv
- OpenAI Agent SDK integration returning structured JSON
- Neon PostgreSQL persistence via Prisma schema
- Session cookie based history tracking

## Workspace layout

- frontend: Next.js application
- backend: FastAPI API service
- specs: Spec Kit feature artifacts
